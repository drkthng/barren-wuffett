<objective>
Fix two startup bugs and add a regression test for the trigger logic.

BUG #1 — On load the game boots straight into the boss fight. Cause: a freshly-loaded
player parked INSIDE the boss zone (the save was written by enterBoss() while standing in
the zone) overlaps boss_trigger on the very first update() tick, because TriggerSystem
starts with an empty consumed set. There is also no boss_01_defeated guard, so a beaten
boss re-triggers on every load.

BUG #2 — A stray "WAKE UP IN HOSPITAL!" heading + "TAP OR WAIT TO CONTINUE" hint float on
screen at startup. Cause: HospitalOverlay hides backdrop + panel container at construction,
but headingText/hintText/feeText are created with no setVisible(false) (Phaser text
defaults to visible) and live outside the panel container, so the container's
setVisible(false) does not hide them.

Purpose: A correct cold start — overworld appears, nothing auto-launches, no stray text.
Output: HospitalOverlay fix, TriggerSystem.armLoadPosition + buildWorld wiring, regression test.
</objective>

For each [zone, def] in LEVEL_01_ZONES: skip it if this.consumed.has(zone) (so a permanently-consumed

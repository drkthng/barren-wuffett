# Plan 02.1-02 Summary — Slice B: "Characters come alive"

Replaced every placeholder character PNG with cohesive palette-matched pixel-art sprites and wired them through the existing Preloader → entity pipeline: 4-direction walk animation for the player, static sprites for the 3 NPCs and dog, and two distinct boss poses (greed/panic) swapped via setTexture on the existing phase transition.

## What was built

- **7 character sprites** (all original in-house pixel art, palette-locked to Kenney Tiny Town warm tones, CC0/project-owned):
  - `player.png` — 128x16 spritesheet, 8 frames @ 16x16 (0-1=down, 2-3=up, 4-5=left, 6-7=right)
  - `npc_grandpa.png`, `npc_store_clerk.png`, `npc_rival.png` — distinct 16x16 townsfolk
  - `dog.png` — 32x16 side-view dog
  - `boss_mr_market_greed.png` + `boss_mr_market_panic.png` — two 32x48 distinct poses
  - Old single `boss_mr_market.png` deleted
- **ASSET-MANIFEST.md** — provenance table for tileset + 7 sprites; no [ASSUMED] license entries; all CC0/project-owned; LEGL-02 parody confirmed
- **Preloader.ts** — `load.spritesheet('player_sheet', ...)` with frameWidth:16; two boss image loads; `anims.create` loop for player_down/up/left/right (6fps, repeat:-1) in create()
- **Player.ts** — texture switched to 'player_sheet' frame 0; `facing` field added; anim playback after setVelocity (velocity logic unchanged)
- **BossScene.ts** — `bossSprite` class field; create() spawns with greed texture; beginPanicPhase() swaps to panic; beginGreedPhase() restores greed on reset

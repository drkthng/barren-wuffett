# Phase 5 — UI Design Contract

> Visual and interaction contract for frontend phases. Generated by gsd-ui-researcher, verified by gsd-ui-checker.

Scope: the hub page (`/`), the daily strip, the locked-card bottom sheet, the install hint, the
"← HUB" button + credit line added to the adventure's two Phaser scenes, and the About overlay.
Everything below is pre-populated from `05-CONTEXT.md` (D-01..D-17) and the `sketch-findings-barren-wuffett`
skill (sketches 001-hub-phone, 002-streak-snowball), both already judged on the user's phone — this
contract records the locked decisions, it does not re-open them.

## Spacing Scale

Declared values, taken from the already-authored `cozy-dusk.css` token set (`sources/themes/cozy-dusk.css`,
promoted to the real build in this phase) — all multiples of 4:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon/sprite gaps, highlight offsets inside sprites |
| sm | 8px | Checklist box gap, badge internal gap |
| sm+ | 12px | Card-to-card gap, strip padding, gap between strip and cards — the project's most-used gap |
| md | 16px | Hub column side padding, default element spacing |
| lg | 24px | Section-level breaks (not yet exercised by Phase 5's flat layout) |
| xl | 32px | Layout gaps (not yet exercised by Phase 5) |
| 2xl | 48px | Major section breaks (not yet exercised by Phase 5) |

Exceptions:
- **≥ 44px tap targets** on every icon-only or short-label control: the install hint's `✕` and
  `HOW?`/`ADD`, the sheet's drag handle hit-area (the visible grab bar is 44×5px but its hit-area
  extends to 44px tall), and the adventure's new "← HUB" button (reusing the existing ≥44px Phaser
  hit-area pattern from `MainMenu.ts`/`Settings.ts`'s legal links).
- Footer links (`Impressum · Privacy`, `made by @Wolfhartvest · about`) get 12px of vertical padding
  to reach a comfortable tap height despite their small visual text size.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 15px (Pixelify Sans) | 400 | 1.5 — card blurbs, checklist label, About body copy |
| Label | 11px (Press Start 2P) | 400 | 1.2 — kickers (`ARCADE · 60 S`), `DAILY #N`, badge `NEW` text |
| Heading | 19px (Pixelify Sans) | 600 | 1.2 — card titles ("Barren vs. Mr. Market") |
| Display | 16px (Press Start 2P) | 400 | 1.2 — hub title "BARREN WUFFETT" |

Exactly 2 weights in use across the two font families: Pixelify Sans 400 (regular) and 600
(semibold); Press Start 2P ships only one weight (it is a bitmap-style pixel font with no bold
cut), so every pixel-font element is 400. Supporting sizes already fixed by the sketch and not
listed above as a named role: tagline 16px, badges 13.5px, footer 14px, streak number 16px
(Press Start 2P, same Display role).

## Color

| Role | Value | Usage |
|------|-------|-------|
| Dominant (60%) | `#221a1d` (`--color-bg`) | Page background behind everything |
| Secondary (30%) | `#31252a` (`--color-surface`), with `#3e2f33` (`--color-surface-2`) as its quiet-pill/stage-tint-base variant | Cards, strip, install hint, bottom sheet, About panel, quiet badge pills |
| Accent (10%) | `#ffc95e` (`--color-primary`) | Reserved for: the hub title, every kicker, `DAILY #N`, the `NEW` badge, the sheet's `OPEN X` primary button and its pressed-state shadow, the number-pop flash on the streak digit. Nothing else uses gold. |
| Destructive | `#e0644f` (`--color-danger`) | Declared in the token set, **unused in Phase 5** — no delete/reset affordance ships this phase. Reserved for a future "reset progress" action if one is ever added; must pair with an explicit confirm step per the Copywriting Contract below |

Accent reserved for: hub title text, all kickers, `DAILY #N` label, `NEW` badge, the bottom sheet's
`OPEN X` button (and its hover/pressed shadow), the streak number's pop-flash animation. Never used
as a generic "interactive element" color.

**Second, independent color layer — per-game accent tokens.** Each game owns its own `--accent`
(`--game-arcade #6fbf4a`, `--game-snowball #a8dcf0`, `--game-ceo #e0874a`, `--game-adventure #b5d86a`),
set inline per card/badge/sheet-header and mixed via `color-mix()` into that element's stage tint,
✓ badge, and checklist box. This is a categorical, per-component theming layer (like a chart's
category colors), not part of the global 60/30/10 budget — it never appears on the background,
page chrome, or any shared control. A locked card substitutes `var(--color-locked) #7a6862` for
its `--accent`.

## UI Considerations

Dismissed as not applicable (relevance-filtered, with reason): **empty/loading** for the card list
and the bottom sheet (the card list is a fixed 4-item config array that is never empty, per D-03;
portraits are code-drawn, synchronously-rendered data-URLs with no network fetch, so no skeleton
or spinner state can exist); **zero-one-many** for the card list (the count is fixed at four and
never varies by data); **long-text/overflow** for the About overlay and the sheet's fixed strings
(both ship short, hand-authored copy with no dynamic length, per `format-shell.md` and
`hub-layout-cards.md`).

Applicable state considerations resolved: 4 covered, 2 backstop, 0 unresolved.

| Category | Element(s) | Status | Resolution / Reason |
|----------|------------|--------|---------------------|
| populated | Cards list (hub) | ✅ covered | The 6 documented hub-state fixtures in `hub-layout-cards.md` ("The hub's real states") cover every populated combination from the Phase 5 preview (`DAILY #1` only, one live card) through day 41 with all three games live — use these as the implementation's test fixtures |
| partial | Best-score badge (cards list) | ✅ covered | The best badge renders only once a score exists; before that it is omitted entirely from the card's badge row — no placeholder dash, no "best: --" |
| overflow | Card blurb + title (cards list) | ✅ covered | `.body` is a flexible column with no fixed height and no truncation CSS in the sketch's pattern; blurb and title wrap naturally — confirmed against the longest approved blurb ("Catch the bargains when Mr. Market panics, dodge his greedy junk. Same market for everyone today.") without clipping |
| long-text | Daily strip numbers (`DAILY #N`, streak count) | ✅ covered | `.hero`/`.strip-main` are flex rows with no fixed width in the sketch's CSS; 3-digit daily numbers (`DAILY #100`+) and streak counts simply widen the row, they never clip |
| error | Daily strip / checklist / streak when on-device storage is fully unavailable (Safari Private Browsing's zero-quota throw, or iOS eviction — Pitfall 12) | 🧪 backstop | **Default used, no outstanding user decision:** render exactly like a brand-new player — solo strip, no checklist, no snowball, no visible error copy. The only user-facing difference is that nothing persists across reloads. Chosen to stay consistent with the already-locked no-guilt, no-interruption streak philosophy (D-07; FEATURES.md rule 4) rather than inventing new error copy for an edge case neither `05-CONTEXT.md` nor the sketch addressed. **Flag for confirmation during `/gsd-plan-phase 5` or with the user** if a visible "progress won't be saved this session" notice is preferred instead |
| error | Locked-card sheet's `OPEN X` button when a popup blocker intercepts the navigation | 🧪 backstop | Implement as a real `<a href="https://x.com/{handle}" target="_blank" rel="noopener">` styled as the primary button, not a scripted `window.open()` inside a tap handler — anchor-tag navigation isn't subject to the popup-blocker heuristics that block scripted `window.open`, so no fallback error UI needs to exist |

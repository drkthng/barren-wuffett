The consolidation must land first because `gsd/fix-menu-taps` rewrites the hit areas in `MainMenu.ts`/`Settings.ts`, the same files 05-04 edits for the "← HUB" button (RESEARCH Pitfall 2). The relocation has two concrete break risks found during planning: Phaser loads `assets/...` relative to the page URL (so from `/adventure/` it would request `/adventure/assets/...`), and vite-plugin-pwa injects `./registerSW.js` plus `register('./sw.js', { scope: './' })`, which from `/adventure/` points at files that do not exist. Its default `navigateFallback: 'index.html'` would also serve the hub for every uncached navigation (RESEARCH Pattern 1).
